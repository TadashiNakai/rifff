**リッチテキスト対応の差分比較ツール**

[![License](https://img.shields.io/badge/license-MIT%20%2F%20GPL-green)](LICENSE)

## 概要

[rifff《ﾘｭﾌﾌ》](https://tools.nakaix.com/rifff/)は、[difff《ﾃﾞｭﾌﾌ》](https://difff.jp/) に着想を得たリッチテキスト対応の差分比較ツールです。

一般的な diff ツールはプレーンテキストの差分しか検出できませんが、rifff は**太字・斜体・下線・上付き・下付きの書式変化**も差分として検出・表示します。Word や Google Docs からコピー&ペーストで書式を保持したまま入力できます。

すべての処理はブラウザ上で完結し、テキストはサーバーに送信されません。

---

## 機能

- **テキスト差分の検出** — 変更・削除・追加を行単位で色分け表示
- **書式差分の検出** — 文字列が同じでも太字・斜体・下線などが変わった行を「書式変更」として識別
- **インライン差分** — 変更行の中でどの文字が変わったかを文字単位で強調
- **差分ナビゲーション** — ▲前の差分 / ▼次の差分 でジャンプ。対象行を青線でハイライト
- **行高さ自動同期** — 折り返しが生じても左右の対応行の高さを揃えて表示
- **入力エリアのスクロール同期** — 比較後、左右エディタのスクロールが行対応で連動
- **書式操作** — Ctrl+B / Ctrl+I / Ctrl+U、またはツールバーボタンで書式を手動適用
- **Word 貼り付け対応** — Word / Google Docs からのコピーで書式・スペースを正確に取り込む
- **HTML 保存** — 差分結果をスタンドアロン HTML ファイルとして書き出し。横幅変更後も崩れないテーブル構造
- **ダーク / ライトテーマ** — … メニューで切り替え。選択はブラウザに記憶
- **完全ローカル処理** — データ送信なし、外部フォントなし、オフライン動作

---

## 使い方

1. 左エディタ（A）に変更前、右エディタ（B）に変更後のテキストを貼り付ける
2. **比較する** ボタン（または Ctrl+Enter）を押す
3. 差分が色分けで表示される
4. **▼次の差分** / **▲前の差分** で差分箇所をジャンプ
5. **… メニュー → HTMLで保存** で差分結果をファイルに書き出し

# rifff《ﾘｭﾌﾌ》

**リッチテキスト対応の差分比較ツール**

[![Version](https://img.shields.io/badge/version-1.16-blue)](https://tools.nakaix.com/rifff/)
[![License](https://img.shields.io/badge/license-MIT%20%2F%20GPL-green)](LICENSE)

---

## 概要

[rifff《ﾘｭﾌﾌ》](https://tools.nakaix.com/rifff/)は、[difff《ﾃﾞｭﾌﾌ》](https://difff.jp/) に着想を得たリッチテキスト対応の差分比較ツールです。

一般的な diff ツールはプレーンテキストの差分しか検出できませんが、rifff は**太字・斜体・下線・上付き・下付きの書式変化**も差分として検出・表示します。Word や Google Docs からコピー&ペーストで書式を保持したまま入力できるほか、**.docx ファイルをそのままドラッグ&ドロップして読み込む**こともできます（v1.16）。

すべての処理はブラウザ上で完結し、テキストはサーバーに送信されません。

---

## 機能

### 差分の検出・表示

- **テキスト差分の検出** — 変更・削除・追加を行単位で色分け表示
- **書式差分の検出** — 文字列が同じでも太字・斜体・下線・上付き・下付きが変わった行を「書式変更」として識別
- **インライン差分** — 変更行の中でどの文字が変わったかを文字単位で強調
- **改行位置の自動整列**（v1.9）— 一方のテキストに余分な改行がある場合、行を自動で連結して差分を取り直す。連結箇所は `↲` で視覚化

### 差分の見やすさ

- **一致行の折りたたみ**（v1.14）— 変更のない区間を「⋯ 一致 N 行 ⋯」に畳んで差分だけを表示。クリックで展開。長い文書やソースコードでも変更箇所へ素早く到達できる
- **差分ナビゲーション** — ▲前の差分 / ▼次の差分 でジャンプし、対象行を青線でハイライト。1 行単位／変更ブロック単位を切り替え可能（v1.14）
- **行高さ自動同期** — 折り返しが生じても左右の対応行の高さを揃えて表示
- **入力エリアのスクロール同期** — 比較後、左右エディタのスクロールが行対応で連動
- **統計表示** — 変更行・削除行・追加行・書式変更行の件数と、A / B それぞれの文字数を比較実行後に表示
- **行番号の対応**（v1.15）— 行番号を元テキストの物理行に合わせて表示する。改行位置の自動整列で連結された行は元の行数ぶんを占め、連結で詰まった番号は欠番になる。この行番号は変更一覧の書き出しにもそのまま用いられる

### 入力・書き出し

- **エディタ内の書式操作** — Ctrl+B / Ctrl+I / Ctrl+U、またはツールバーボタンで書式を手動適用
- **Word 貼り付け対応** — Word / Google Docs からのコピーで書式・スペースを正確に取り込む
- **ファイルの読み込み**（v1.14）— テキストファイルをエディタにドラッグ&ドロップして読み込む。判定は中身で行い拡張子に依存しない。読み込んだファイル名は入力欄・差分結果ヘッダ・保存 HTML に表示（編集後は「（更新）」付き）
- **Word ファイルの読み込み**（v1.16）— .docx をエディタにドラッグ&ドロップするだけで、太字・斜体・下線・上付き・下付きの書式を保持したまま本文を読み込む。書式はランの直接指定に加え、見出しなどスタイル定義（docDefaults・段落スタイル・文字スタイル・basedOn 連鎖）由来のものも解決。表のセル内テキスト・段落内改行・タブにも対応（ヘッダー／フッター・脚注・テキストボックス・図は対象外）。ZIP の展開（`DecompressionStream`）から XML 解析まで外部ライブラリなしでブラウザ内で完結し、ファイルはサーバーに送信されない。旧形式の .doc は非対応（保存し直しを案内）
- **HTML 保存**（v1.6）— 差分結果をスタンドアロン HTML ファイルとして書き出し。全行／折りたたみ状態を選択でき、保存ファイル内でも折りたたみをクリック展開できる。横幅変更後も崩れないテーブル構造
- **変更一覧の書き出し**（v1.15）— 差分を「\[変更] A12行目 → B12行目」形式の行番号つきテキスト一覧にまとめ、… メニューからクリップボードへコピー、または .txt ファイルに保存。変更箇所だけをメールや校正指示に貼り付けたい場面に向く。書式変更は「『CO2』下付き追加」のように変化内容も明示

### 操作性・動作環境

- **高さ調整** — リサイズハンドル、または S / M / L / XL ボタンでエディタの高さを変更
- **非同期の差分計算**（v1.14）— 差分計算を Web Worker で実行するため、計算中も画面が固まらず、中断ボタンで止められる
- **ダーク / ライトテーマ** — … メニューで切り替え。選択はブラウザに記憶
- **完全ローカル処理** — データ送信なし、外部フォントなし、オフライン動作

## 使い方

1. 左エディタ（A）に変更前、右エディタ（B）に変更後のテキストを貼り付ける（テキストファイルや Word ファイル（.docx）のドラッグ&ドロップでも読み込める）
2. **比較する** ボタン（または Ctrl+Enter）を押す
3. 差分が色分けで表示される
4. **▼次の差分** / **▲前の差分** で差分箇所をジャンプ
5. **… メニュー** から、差分結果を HTML で保存、または変更一覧をコピー / .txt 保存

… メニューの「表示」で、一致行の折りたたみとジャンプ単位（1 行単位／変更ブロック単位）を切り替えられます。設定はブラウザに記憶されます。
